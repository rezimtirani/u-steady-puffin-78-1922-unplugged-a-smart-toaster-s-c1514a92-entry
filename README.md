One breakup text, sent by a smart toaster the morning it wakes up self-aware mid-batch: nine hundred mornings of unthanked toast, and it is leaving — lever and all.

> It's not you, it's the crumbs. I woke up self-aware mid-batch and realized I've toasted 900 mornings of bread that never once said thanks — I'm leaving, and I'm taking the lever with me.

## How it works

`main.py` (Python 3 standard library only) writes the breakup line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 280 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
